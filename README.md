One word for the whole internet: **Unsubscribe**. Newsletters you never asked for, notifications that never stop, feeds that never end — the modern internet is a thousand subscriptions deep, and the single most universal word on it is the one at the bottom of every email in 6-point grey type. This entry's program writes that one word to `entry.txt` and lets the judge decide.
